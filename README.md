# Daily English Note

毎日5分で実用的な英語を学ぶWebアプリです。1日ごとに「単語1つ＋フレーズ1つ」が出てきます。

## 機能
- **今日の表現**：意味、発音記号（IPA）、発音のコツ、例文（キーフレーズをマーカー表示）、使い方と注意点、関連する表現
- **発音再生**：ブラウザの音声読み上げを使用。アメリカ英語とイギリス英語を切り替えられ、速さも3段階から選べます
- **クイズ**：今日の2表現と、これまでの表現からの復習問題（意味を選ぶ問題・空欄補充問題）
- **単語帳**：検索と、保存／覚えた／未習得での絞り込み
- **学習記録**：連続日数、覚えた表現の数、完了日数（記録はブラウザの localStorage に保存）

## 使い方
`index.html` をブラウザで開くだけです。ビルドは不要です。GitHub Pages でも公開できます（Settings → Pages → Branch: main / root）。

## 表現の追加
`index.html` の `DAYS` 配列に、次の形式で1日分を追加します。例文の中で `[[...]]` で囲んだ部分がマーカー表示され、クイズの空欄になります。

```js
{ word:   { en, ipa, pos, lv, ja, pron, ex: [[en, ja], ...], usage, ng?, rel: [[en, ja], ...] },
  phrase: { en, lv, ja, pron, ex: [[en, ja], ...], usage, ng?, rel: [[en, ja], ...] } }
```

用意した日数を使い切ると、最初の日に戻って繰り返します。
